## 1. Real-Phone Mobile Test

### Finding

During testing on a real phone at 100% browser zoom, the Biomedical Maintenance Triage case study had text clipped at the right edge of the viewport.

The content became visible when the browser was zoomed out, indicating an intrinsic-width/overflow problem rather than a font-size problem.

### Fix

Added mobile overflow protection to the case-study content and ensured the surrounding article could shrink correctly.

Changes included:

- `min-width: 0` on the case-study article
- `min-width: 0` on case-study content
- Horizontal scrolling for code blocks where necessary

### Verification

The case study was retested on a real phone at 100% zoom.

**Result: PASS**

Commit:

`3ce5215 – fix mobile case study overflow`

## 3. Accessibility Audit

An initial accessibility review identified two issues that required action.

### Issue A – Accent Text Contrast

Small uppercase eyebrow/accent labels were using the bright cyan accent color against light backgrounds.

The initial contrast was approximately 2.4–2.8:1, below the WCAG AA 4.5:1 requirement for normal-sized text.

### Fix

Introduced a dedicated text-safe accent token:

```css
--color-accent-text: #087f91;
```

The `.label` utility was changed to use this darker color while the original bright cyan remains available for decorative elements.

### Final Verification

The live site was tested after deployment.

Rendered accent text:

`#087f91`

Background:

`#f8fafc`

Calculated contrast:

approximately `4.53:1`

**Result: PASS – WCAG AA**

---

### Issue B – Skip to Main Content

The initial accessibility audit identified a missing/incorrect skip-navigation experience.

### Fix

Added a keyboard-accessible skip link:

```tsx
<a href="#main-content">
  Skip to main content
</a>
```

The link is visually hidden until it receives keyboard focus.

The main content landmark was given the matching identifier:

```tsx
<main id="main-content">
```

### Verification

The production site was refreshed and tested using keyboard navigation.

The skip link appeared when tabbing from the top of the page and correctly targeted the main content.

**Result: PASS**

Commit:

`35a3e2d – fix accessibility contrast and skip link`
